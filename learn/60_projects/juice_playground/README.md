# Juice Playground

A tiny platformer sandbox for learning game feel: jump dust, landing dust,
run dust, squash & stretch, screen shake. No real art — just rectangles and
particles — to prove that "looks good" is mostly motion and feedback.

Start with:
- `LESSON.md`

Runnable answer lives in:
- `learn/95_solutions/projects/juice_playground`

Do this AFTER `30_fundamentals/t10_particles_screenshake`. The dust here
reuses the same particle-pool pattern. The functions you write transfer
directly into `60_projects/sokoban` and later `sauce/`.
