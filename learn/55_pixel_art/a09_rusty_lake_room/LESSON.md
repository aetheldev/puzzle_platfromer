# A09 — The Rusty Lake Room

Goal: one full scene mockup — the visual target of your detective
game. Everything so far converges: forms (a03), palette (a04), icons
(a05), character (a06), tiles (a08). New skill: COMPOSITION + MOOD.

Canvas: 320x180 (16:9, scales 3x to 960x540 — your lesson window size).

## Rusty Lake's Actual Tricks (study, then steal)

Open Rusty Lake screenshots (Cube Escape is free). Notice:

1. **Flat frontal rooms.** One wall, floor, no fancy perspective.
   Theater stage, not 3D. GREAT for beginners — zero perspective math.
2. **Muted palette + one accent.** Desaturated browns/greens/grays,
   then ONE saturated color where they want your eye (red door, glowing
   item). That accent = your puzzle hotspot language (t13!).
3. **Big empty wall space.** Not afraid of plain areas. Detail only
   where interaction lives.
4. **Symmetry, broken once.** Centered furniture, then one off-center
   element = unease. Their horror is composition, not gore.

## Build Order (blocking like a t12 integration room)

1. **Three bands:** wall color (top 2/3), floor color (bottom 1/3),
   1-2px baseboard line between. Done = room exists.
2. **Furniture as flat silhouettes:** desk, chair, painting, door,
   drawer (your t13 hotspots!). Dark flat shapes first — composition
   readable before any rendering. Move things until the eye flows:
   door (goal) gets the accent later, desk (interaction) near center.
3. **Render with a03/a05 recipes:** light source = the lamp or window
   you placed. Forms: desk = cube, lamp = ball+cylinder.
4. **Mood pass:** darken corners (vignette by hand or dither bands —
   a03 dithering's moment), light pool around the lamp, ONE accent
   color on the key puzzle object.
5. **Inhabit:** place Detective A sprite (a06) in the scene. Scale
   check: door taller than detective, desk waist-height. Fix now —
   this calibrates ALL future asset sizes.

## The Two-Detective Test

Your co-op gimmick: duplicate the finished scene, recolor to a second
palette (warm vs cold — a04 mood swap drill, now for real), change
one object between versions (the parallel-worlds hint mechanic!).
Side by side = your game's core screenshot. This image is worth more
than any design doc — pin it.

## Drills

1. The room, full build order above
2. 100% zoom + squint: wall/floor/furniture separate? accent pops?
3. Show a friend for 3 seconds: "what do you click first?" — if not
   your accent object, raise its contrast
4. Palette-swap second version + one changed object

## Exit Criteria

- [ ] Scene reads at 100%: room, mood, one obvious focus
- [ ] Detective sprite scales correctly inside it
- [ ] Two-world pair exists (THE screenshot)
